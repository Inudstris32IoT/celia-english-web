Configurar acceso al panel

Ir al panel

1. Crea una llave de GitHub (solo la primera vez o cuando venza)

  1. Con la cuenta dueña del repositorio, abre GitHub → Fine-grained token nuevo.
  2. Token name: panel-celia. Expiration: la más larga que permita (puedes renovarla después).
  3. Repository access: Only select repositories → celia-english-web.
  4. Permissions → Repository permissions → Contents: Read and write. No actives nada más.
  5. Pulsa Generate token y copia la llave (empieza con github_pat_).

2. Crea o actualiza un usuario

La llave se cifra en este navegador con la contraseña que elijas y se guarda cifrada en el repositorio. Nunca se guarda ni se envía sin cifrar.
